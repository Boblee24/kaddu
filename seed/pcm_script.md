# Pidgin (pcm) recording script

Record each line as its own clip with your phone's voice recorder. Each clip should be 4–8 seconds and in a quiet room.
Speak naturally, the way you'd normally talk. If you say it differently from what's written, that's fine, but **edit the line below to match exactly what you said.**
Name the files `pcm_01`, `pcm_02`, … to match the numbers here.
